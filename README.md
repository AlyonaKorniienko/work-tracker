# Трекер робочого часу

Персональний трекер: таймер по напрямках і задачах, тижневий баланс годин, аналітика та чек-іни стану.

Дані зберігаються у приватній Google Таблиці власниці. Ключ доступу не входить до коду — він вводиться один раз і залишається на пристрої, тож без нього сторінка нічого не показує і нікуди не звертається.
